# Source references

These manifests record the exact upstream sources consulted during development:

- `sources.json`: Linux USB ABI and Realtek RTL8153 register/revision definitions.
- `lldpd-source.json`: LLDP decoding reference.
- `cdp-sources.json`: CDP framing and checksum reference.

File names in manifests identify upstream reference copies, not required local
files. URLs include fixed commit IDs; SHA-256 values identify the researched
content. No downloads are needed to run the tester or its Python tests.
See [third-party notices](../THIRD_PARTY_NOTICES.md) for attribution.
